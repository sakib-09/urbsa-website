# URBSA Website

Official website for **URBSA — University of Regina Bangladeshi Students' Association**, a student community for Bangladeshi students at the University of Regina (Regina, Saskatchewan, Canada).

🔗 **Live site:** https://sakib-09.github.io/urbsa-website/

## What the site covers
- **About** — who URBSA is: culture, community, and newcomer support
- **Events** — recent events (Bangladeshi Night 2026, Independence Day, URBSA Iftar 2026, Mother Language Day, Movie Night, Eid celebrations) with ticket/info links
- **Webinar** — spotlight section for the URBSA webinar (details placeholder)
- **Join** — membership form call-to-action
- **Contact** — Instagram link and location

## Tech stack
- Pure static HTML, CSS, and JavaScript (no build step, no frameworks)
- Inter font via Google Fonts CDN
- Custom SVG logo mark (original artwork)
- GitHub Pages hosting
